## 🌟 About Me

**A problem-solver who happens to love design — and never stops learning.**

I'm a UI/UX Designer and Frontend Developer based in Baguio City, Philippines, and a BS Information Technology graduate. I like living at the intersection of design and code, building things that look good and actually work well for the people using them.

**What I'm into:**
- Turning messy problems into clean, intuitive interfaces
- Building full-stack apps, from database to UI
- Wireframing and prototyping in Figma before writing a line of code
- Always picking up something new — currently exploring more backend and cloud work
